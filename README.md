# 🖼️ MobileNet SSD Object Detection

### AI-Powered Object Detection System

MobileNet SSD Object Detection is a computer vision project that uses **MobileNet-SSD**, **OpenCV**, and **Python** to detect and locate multiple objects in an image. The system identifies objects, draws bounding boxes, and displays confidence scores for each detection.

## 🎯 Features

* Multi-object detection
* Bounding box visualization
* Confidence score display
* Fast and efficient predictions
* Interactive Streamlit interface

---

## 🧠 How It Works

1. Upload an image.
2. Preprocess the image using OpenCV.
3. Run the MobileNet-SSD model.
4. Detect objects and confidence scores.
5. Display the annotated output image.
